# 📦 SmartStock
![Google Sheets](https://img.shields.io/badge/Google%20Sheets-34A853?logo=googlesheets&logoColor=white) ![Apps Script](https://img.shields.io/badge/Apps%20Script-4285F4?logo=google&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

> Inventory Dashboard for Small Businesses built with **Google Sheets** and **Google Apps Script**.

SmartStock is a lightweight inventory management system that helps small businesses track stock movements, monitor revenue and profit, identify low-stock products, and visualize business performance through an interactive dashboard.

- Interactive Inventory Dashboard

# 📋 How It Works

1. User clicks **Add Transaction**
2. Selects Product
3. Chooses Stock In or Stock Out
4. Inventory updates automatically
5. Dashboard refreshes instantly
6. Business insights update automatically
